# 种子扩展流程说明

## 功能概述

新的种子扩展流程实现了以下功能：

1. **种子输入**: 点击种子节点时，显示输入框让用户输入种子标题和提示词
2. **文本扩展**: 基于提示词调用LLM服务进行文本扩展
3. **文本查看**: 用户可以查看和编辑扩展后的文本
4. **GNN处理**: 将扩展后的文本发送到GNN服务进行实体关系识别
5. **图谱渲染**: 根据GNN返回的节点和边数据渲染知识图谱

## 重要变更

- **移除了自动扩展功能**: 不再有自动生成节点的逻辑
- **专注于种子处理**: 只有种子节点可以进行文本扩展和GNN处理
- **手动控制**: 所有节点生成都需要用户明确操作

## 技术实现

### 1. API路由

- `/api/expand` - 文本扩展服务（已存在）
- `/api/gnn` - GNN服务，处理实体关系识别（新增）

### 2. 组件更新

#### ExpandOptionsPopover
- 添加了种子输入界面
- 集成了文本扩展功能
- 添加了GNN处理按钮
- 支持查看和编辑扩展文本

#### GraphCanvas
- 更新了节点点击逻辑，种子节点总是显示弹窗
- 添加了文本扩展处理函数
- 添加了GNN处理函数
- 集成了GNN返回数据的渲染逻辑

### 3. 数据流程

```
用户点击种子节点
    ↓
显示种子设置弹窗
    ↓
用户输入标题和提示词
    ↓
点击"扩展文本"按钮
    ↓
调用/api/expand进行文本扩展
    ↓
显示扩展后的文本（可编辑）
    ↓
点击"生成知识图谱"按钮
    ↓
调用/api/gnn进行实体关系识别
    ↓
渲染新的节点和边到图谱中
```

## 使用说明

1. 点击初始的种子节点
2. 在弹窗中输入种子标题和提示词
3. 点击"扩展文本"按钮，等待文本扩展完成
4. 查看扩展后的文本，可以编辑调整
5. 点击"生成知识图谱"按钮，等待GNN处理
6. 查看生成的知识图谱节点和关系

## 注意事项

- **已移除自动扩展**: 不再有自动生成节点的功能
- 目前GNN服务返回的是模拟数据，实际部署时需要连接真实的GNN服务
- 文本扩展功能依赖LLM服务配置
- 所有操作都有错误处理和加载状态显示
- 只有种子节点支持文本扩展和GNN处理功能
