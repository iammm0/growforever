# 节点自动布局算法

## 算法概述

实现了智能的节点自动布局算法，根据节点数量采用不同的布局策略：

### 1. 单节点布局
- **条件**: `totalNodes <= 1`
- **策略**: 居中放置
- **位置**: `(400, 300)`

### 2. 小数量节点布局（网格布局）
- **条件**: `2 <= totalNodes <= 4`
- **策略**: 网格排列
- **计算方式**:
  - 列数: `Math.ceil(Math.sqrt(totalNodes))`
  - 行数: `Math.ceil(totalNodes / cols)`
  - 节点间距: `250px`
  - 中心点: `(400, 300)`

### 3. 大数量节点布局（圆形布局）
- **条件**: `totalNodes > 4`
- **策略**: 圆形分布
- **计算方式**:
  - 半径: `Math.max(200, totalNodes * 30)`
  - 角度: `(2 * Math.PI * index) / totalNodes`
  - 中心点: `(400, 300)`

## 布局特点

### 网格布局优势
- 适合少量节点（2-4个）
- 整齐有序的排列
- 便于阅读和理解关系

### 圆形布局优势
- 适合大量节点（5个以上）
- 避免节点重叠
- 最大化利用空间
- 美观的对称分布

## 参数配置

```typescript
const NODE_SPACING = 250    // 节点间距
const CENTER_X = 400        // 布局中心X坐标
const CENTER_Y = 300        // 布局中心Y坐标
```

## 使用场景

1. **知识图谱生成**: 根据GNN服务返回的实体数量自动选择布局
2. **关系可视化**: 保持节点间合理距离，便于观察连接关系
3. **响应式布局**: 适应不同数量的节点，提供最佳视觉效果

## 扩展性

算法具有良好的扩展性：
- 可以轻松调整间距参数
- 支持添加新的布局策略
- 可以根据节点类型采用不同布局
- 支持动态调整布局参数
